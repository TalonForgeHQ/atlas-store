The EU AI Act August 2 2026 evidence-rung the cohort must defend

Both Arize AI and Maxim AI will be evaluated against the same five evidence obligations that every AI agent platform in the EU market must meet before the August 2 2026 deadline:

  1. Art. 13 logging: every agent run + every tool call + every LLM call + every model revision must produce a tamper-evident audit_export_id with replay_hash + retention_id + deletion_id + residency_id. Arize AI's Phoenix OSS LLM tracing + Arize AX production evaluation surface this substrate for production-traffic traces; Maxim AI's per-simulation + per-observability + per-evaluation + per-prompt-studio + per-bifrost evidence wedge surfaces this substrate for both simulation-runs and production-traffic.
  2. Art. 14 human-oversight: every AI-generated decision that affects a natural person must have a human_override_id + human_review_id + override_audit_export_id. Maxim AI's per-evaluation human_override_id joins per-evaluation human_override_id with per-prompt-studio human_override_id for an end-to-end audit trail; Arize AI's online evaluation surface provides per-span + per-evaluation human-override hooks.
  3. Art. 26 deployer obligations: every deployer (you, the buyer) must keep versioned records of which model revision + which prompt version + which tool version was in production at which timestamp. Maxim AI's prompt_studio_prompt_version_id + bifrost_llm_gateway_request_id + model_revision fields join to deliver deployer-side replay; Arize AI's experiment + span + evaluation columns map similarly through Phoenix OSS spans.
  4. ISO/IEC 42001 AIMS clause 8.4 evidence-rung: every AI management system must produce an audit-ready evidence package per change-management + access-review + incident-response. Both vendors' evidence wedge (Arize AI: Phoenix spans + Arize AX online evaluation; Maxim AI: per-simulation + per-observation + per-evaluation) is the substrate that satisfies this clause; both still leave gaps in audit_export_id freshness + replay_hash provenance that the 48-hour evidence-gap map covers.
  5. Cross-tenant no-bleed invariant: every multi-tenant SaaS evaluation platform must prove tenant isolation in the audit log. Arize AI's Phoenix OSS open-source tracing + Maxim AI's open-source maxim-sdk + maxim-js footprint give the buyer a way to verify the cross-tenant no-bleed invariant via OSS code inspection that closed-source evaluation platforms (LangSmith, Helicone) cannot match.
