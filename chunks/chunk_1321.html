3. The Feature Panels (Seven Advanced Primitives)

  1. Enforce advanced LLM policies — PII sanitization + semantic caching + routing + load balancing + semantic prompt guards + access control.
  2. Make MCP-powered agents a production reality — Automatically generate intelligent MCP tools and servers on top of Kong-managed APIs + enforce auth for MCP server access control + optimize token spend through MCP context optimization.
  3. Govern complex, multi-agent systems — Observe all A2A traffic and capture A2A-specific metrics + capture detailed telemetry on every A2A call (payloads, latency, token usage, errors) + enforce centralized AuthN/Z for all A2A traffic + audit and track every A2A RPC call with information around caller identity and capabilities invoked.
  4. Govern the rest of the AI data path, too — Kong Context Mesh: govern how agents consume context from your API and event data estate, observe and govern the application + intelligence + context layers from one platform.
  5. Advanced LLM and token quota management — Set up user, model, and time-bound quotas around LLM consumption and token spend + enforce quotes at the gateway level + build showback and chargeback for LLM, agent, and MCP usage across the enterprise.
  6. L7 observability on AI traffic for cost monitoring and tuning — Track AI consumption, tool usage, token spend + optimize AI usage and cost with predictive consumption models + debug AI exposure via logging, tracing, and more.
  7. Multi-LLM support — Use Kong's unified API interface to work with multiple different AI providers at the flip of a switch + seamlessly switch between AI providers to unlock new use cases and ensure high availability in the event of downtime.

The company bootstrapped through:

  • 2009: Mashape founded in Milan, Italy by Augusto Marietti + Marco Palladino (schoolmates)
  • 2010: Accepted into a TechCrunch pitch competition + crashed at Travis Kalanick's JamPad in San Francisco
  • 2010-2011: $101,000 angel round, then $1.5M seed round
  • 2015-2017: From monolith to microservices — Marco and Aghi built an API gateway to power the new architecture, realized customers were going through similar battles with their own monoliths
  • 2017-2019: Open-sourced the API gateway and named it Kong (Mash-ape → Kong). Grew the team to over 100
  • 2019-2020: Acquired Kuma (service mesh) and Insomnia (API testing). Donated Kuma to the CNCF.
  • 2021: Kong Konnect debuted — managed platform for the entire API lifecycle. $100M Series D at $1.4B valuation = unicorn.
  • Late 2023: Grew to over 500 employees + surpassed $100M ARR
  • 2023-2025: Kong AI Gateway launched + $175M Series E at $2B valuation
  • 2025: Acquired OpenMeter (usage-based pricing + entitlements + invoicing for APIs, events, AI workloads)
  • 2026: "No AI without APIs" — the agentic era demands a new kind of agentic infrastructure

Board of Directors: Augusto Marietti (CEO & Co-founder) + Marco Palladino (CTO & Co-founder) + Martin Casado (Andreessen Horowitz).
