The 5 evidence gaps behind one AI generation

  1. Token + cost join: most analytics events capture $ai_input + $ai_output but not the input/output token counts or the cost, so the team cannot roll up cost-per-generation against revenue per user.
  2. Span + trace join: most events capture the generation but not the $ai_span_id + $ai_trace_id, so a developer tracing a multi-step agent loop has to reconstruct the trace from logs that may have rotated.
  3. Tool call join: most events capture model_id but not the $ai_tool_call_id + the tool-call inputs/outputs, so the team cannot answer which tool is consuming tokens and which tool is ROI-positive.
  4. Model revision join: most events capture model_id but not $ai_model_revision, so a regression caused by a model upgrade cannot be tied back to the exact revision that fired.
  5. Feedback join: most events capture the generation but not $ai_feedback_id, so the team cannot correlate a thumb-up / thumb-down with the exact generation that produced it.
