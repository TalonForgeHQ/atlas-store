1. What is Vocode?

Vocode (vocode.dev) is an open-source MIT-licensed library — Python SDK + TypeScript SDK — that lets developers build voice-based LLM agents by composing four named primitives: Transcribe, LLM, Respond, and Synthesize. Each primitive is provider-agnostic and ships with a swap-in surface for the major vendor stack: Azure Speech, Deepgram, OpenAI (Whisper + GPT-4o realtime), Play.ht, Anthropic Claude, and ElevenLabs. The result is a runtime where every voice-agent decision (which STT, which LLM, which TTS, which turn-taking policy, which barge-in mode) is a composable configuration rather than a vendor lock-in.

2. Why open-source matters here

Every commercial conversational-voice stack — Vapi, Cognigy, Retell, Sierra, PolyAI — is closed-source. You consume the API, you don't audit the runtime. Vocode flips that: the entire agent loop is vocode-core on github.com/vocodedev/vocode-core under MIT, which means the prompts, the turn-taking policy, the interrupt handling, the latency budget, the audio chunk routing, the WebSocket session lifecycle, and the end-of-speech / barge-in event surface are all readable, patchable, and self-hostable. For any procurement or compliance team operating under EU AI Act Art. 13 (logging), Art. 14 (human oversight), or ISO/IEC 42001 AIMS clause 8.4 (evidence-rung), MIT + self-host is the only deployment model that lets you put every line of the agent under your own audit scope.

3. The four primitives

  • Transcribe — streaming STT. Azure Speech / Deepgram / OpenAI Whisper. Configurable endpointing, language, profanity filter.
  • LLM — turn-taking decision layer. OpenAI / Anthropic / local. Supports streaming, tool calls, JSON-mode, system-prompt versioning.
  • Respond — utterance synthesis trigger, with barge-in detection, interrupt handling, end-of-speech event emission.
  • Synthesize — TTS. Play.ht / ElevenLabs / Azure / OpenAI TTS. Voice ID, speed, pitch, emotion, language.
