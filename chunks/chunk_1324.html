2. The Stagehand Open-Source Framework (13K+ Stars)

Stagehand is Browserbase's crown jewel — the canonical open-source AI-native browser-automation framework at github.com/browserbase/stagehand with 13K+ GitHub stars. Stagehand differs from generic Puppeteer/Playwright because it was designed from day-1 for LLM-driven browser control: it exposes a small set of high-level AI primitives (act / extract / observe / agent) on top of the underlying CDP fleet.

  • act: Perform an action described in natural language (e.g. "click the blue submit button").
  • extract: Pull structured data from the current page using a Zod schema.
  • observe: Enumerate possible actions without committing to one.
  • agent: Hand off a multi-step task to an LLM-driven agent loop with replanning.

Combined with the Stagehand Studio debugger and the cloud-hosted Stagehand deployment, this is the cohort's canonical AI-native browser-automation substrate.
